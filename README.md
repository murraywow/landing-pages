# Music Promotion Landing Pages

This repository contains a front-end-only static site for music promotion landing pages.

## Features

- Dedicated landing pages per release
- Placeholder for a Meta pixel snippet
- Clickable Spotify and Apple Music links
- Cover image included in the page markup
- Ready to host on GitHub Pages

## Local preview

Open [index.html](index.html) in a browser, or serve the folder with a simple static server.

## GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, enable GitHub Pages.
3. Choose the root folder or the main branch as the publishing source.
4. Your site will be available at:
   https://<your-username>.github.io/landing-pages/
